## Goal

At the end of this plan the repository has:

1. a frozen copy of the revision-2 outputs (`outputs/categorical_baseline_rev2/`);
2. `analyse_graphs.py` and `render_side_by_side.py` able to read any outputs root;
3. a new `categorical/graph_analysis/check_views.py` (structural numbers per view);

6. the baseline numbers of all tools in `outputs/plans_baseline/`.

### 4. Write `categorical/graph_analysis/check_views.py`

Usage: `python categorical/graph_analysis/check_views.py <outputs_root> <out.json> <dataset> [...]`.

Follow the style of `analyse_graphs.py` (module docstring with usage, plain functions,
`if __name__ == "__main__":`). Import the variant list from `analyse_graphs` the way
`latent_reachability.py` does (`sys.path` insert of `categorical/graph_analysis`, then
`import analyse_graphs as A`, use `A.VARIANTS`).

For every dataset and every view in `A.VARIANTS`, load the structure JSON
(`next((root / ds / vname).glob(pattern))`) and compute:

| key | definition |
|---|---|
| `graph_nodes` | `len(structure["graph"]["nodes"])` |
| `labelled_nodes` | ids of top-level `structure["nodes"]` entries whose id has no `->` and whose label is non-empty |
| `orphans` | ids in `graph["nodes"]` that are not in `labelled_nodes` or have no incident edge |
| `edges` | number of edges in `graph["links"]` (fall back to `graph["edges"]`) |
| `class_inflow` | sum of `weight` over edges whose target label starts with `"Class "` |
| `class_inflow_ratio` | `class_inflow / class_inflow(BASIC)` (1.0 for BASIC itself) |
| `classes_present` | sorted list of class labels present |
| `n_target_names` | `len(structure.get("target_names", []))` |
| `flow_violations` | number of labelled, non-class nodes with in-degree ≥ 1 and out-degree ≥ 1 where `abs(in_w - out_w) > 1e-6 * max(in_w, out_w, 1)` (`in_w`/`out_w` = summed incoming/outgoing weight) |
| `max_label_len`, `predicate_chars` | max and sum of `len(label)` over `labelled_nodes` |
| `grouping_status` | `structure.get("grouping_status")` (absent today; 8a adds it) |

Write `{dataset: {view: {...}}}` to `<out.json>` (lists for sets, `indent=1`) and print one
markdown table: `dataset | view | graph nodes | orphans | edges | class inflow ratio |
classes present / targets | flow violations`. Use short view names (`BASIC`, `GROUPED`, `SPLIT`,
`CONJ`, `DEDUP`).

Note on `flow_violations`: in a BASIC DPG, a node that starts some traces has more outgoing than
incoming weight, so BASIC itself has violations. What matters later (1a/1b) is that a view has
**no more** violations than BASIC.

### 6. Create the test package

`tests/categorical/__init__.py`: empty.

`tests/categorical/conftest.py`:

```python
"""Helpers for the categorical-view tests: build small structure payloads
shaped like the ones run_all_categorical_experiments.save_dpg_structure_json
writes, and read the views back."""
import pathlib
import sys

import networkx as nx
import pytest
from networkx.readwrite import json_graph

ROOT = pathlib.Path(__file__).resolve().parents[2]
for _p in (ROOT, ROOT / "categorical"):
    if str(_p) not in sys.path:
        sys.path.insert(0, str(_p))


def make_structure(labels, edges, **extra):
    """``labels``: {node_id: label}; ``edges``: [(src, dst, weight)].
    Returns a BASIC-shaped structure dict (top-level ``nodes`` + node-link ``graph``)."""
    g = nx.DiGraph()
    g.add_nodes_from(labels)
    for src, dst, w in edges:
        g.add_edge(src, dst, weight=float(w))
    structure = {
        "nodes": [{"id": nid, "label": lab} for nid, lab in labels.items()],
        "graph": json_graph.node_link_data(g),
    }
    structure.update(extra)
    return structure


def view_edges(structure):
    """{(src, dst): weight} of a view (accepts ``links`` or ``edges``)."""
    g = structure.get("graph", {})
    links = g.get("links") or g.get("edges") or []
    return {(str(e["source"]), str(e["target"])): float(e["weight"]) for e in links}


def view_labels(structure):
    """{node_id: label} of the real (non-pseudo) nodes of a view."""
    return {str(n["id"]): n["label"] for n in structure["nodes"] if "->" not in str(n["id"])}


@pytest.fixture
def mk():
    return make_structure
```

## Validation (acceptance criteria)

All numbers come from the baseline, so they must match the report:

1. `check_views` `class_inflow_ratio`: accidents_mining CONJ and DEDUP 2.68; adult_subset SPLIT 1.51,
   CONJ/DEDUP 3.81; bank_marketing CONJ/DEDUP 4.46; credit_card_approval and credit_card_visual
   CONJ/DEDUP 1.92; nursery CONJ/DEDUP 3.22; every other cell 1.00 (two decimals).
2. `check_views` bank_marketing GROUPED: `graph_nodes` 28, 27 labelled nodes, 1 orphan.
   No orphans in any SPLIT/CONJ/DEDUP view.
3. `classes_present / n_target_names` matches the report's #9 table (nursery 1/5, obesity 2/7,
   students 2/3, credit/titanic 2/2, the other five 1/2).
4. `outputs/plans_baseline/findings.json`: `n_changed_paths == 0` for every view of every dataset.
5. Mini-grid summary: `conj_iteration_cap` reached at least once (accidents_mining and adult_subset,
   seed 27, 10 trees, `perc_var` 0.005 are known cases); `item3_conj_*` and
   `item4_conj_opposite_ops` have non-zero `wrong from UNSAT`; `item7_*` non-zero.
6. `pytest tests/categorical` passes; `pytest tests/` has the same result as in step 1.

Keep `outputs/plans_baseline/` and `outputs/categorical_baseline_rev2/`. Every later plan
compares against them.
