# 1b — Clones take a proportional share of the original's outgoing weight

**Problem:** report #1, second half. `_clone_node` in the split and conjunction scripts gives the
clone a **full copy** of the original's outgoing weights and leaves the original's weights as they
were, so every clone duplicates traffic. After 1a this is the only remaining source of inflated
weights (e.g. adult_subset SPLIT 1.51×).
**Approach:** flow conservation. A clone made for the incoming edge `u → v` (weight `w_uv`) takes
the share `f = w_uv / in_w(v)` of each of `v`'s outgoing edges, and the original keeps `1 − f`.
**Depends on:** 1a and 8a (same functions; 8a also stops the runaway cloning that would make this
plan's checks meaningless).

## Rationale

`in_w(v)` is the total weight entering `v` (including `u → v`). For a node that no trace starts at,
`in_w(v) = out_w(v)` in BASIC, so the clone's outflow is exactly `w_uv` and the original's outflow
drops by exactly `w_uv`: the total weight into the class nodes stays the same. For a node where
some traces start (#11), the start traffic is shared in the same proportion. That is an
approximation, but it conserves the totals. An exact split would need the traces themselves, and
the transformation scripts do not have them; that alternative is rejected here.

Using `in_w(v)` rather than `out_w(v)` as the denominator guarantees `f < 1` whenever `v` has
another parent with positive weight (the only case where a clone is made), so the original never
ends up with zero-weight edges.

## Changes

1. `categorical/cat_grouping_split.py`, inner `_clone_node(v)` → `_clone_node(v, w_in)`:

   ```python
   def _clone_node(v: str, w_in: float) -> str:
       """Private copy of ``v`` for one incoming edge of weight ``w_in``:
       same label, and the share ``w_in / (v's total incoming weight)``
       of each of ``v``'s *current* outgoing edges, which ``v`` itself
       gives up. The total weight leaving ``v`` and its clone together
       stays what it was. Nothing points to the clone yet -- the caller
       wires up its single incoming edge."""
       nonlocal clone_counter
       clone_counter += 1
       v_copy = f"{v}#{clone_counter}"
       labels[v_copy] = labels[v]
       in_w = sum(w for (_, d), w in edges.items() if d == v)
       share = min(1.0, w_in / in_w) if in_w > 0 else 0.0
       for (s, d), w in list(edges.items()):
           if s == v:
               edges[(v_copy, d)] = edges.get((v_copy, d), 0.0) + w * share
               edges[(s, d)] = w * (1.0 - share)
       return v_copy
   ```

   Both call sites in `_split_then_merge` pass `w_uv`: `_clone_node(v, w_uv)`. Both calls happen
   **before** `del edges[(u, v)]`, so `in_w` still includes `w_uv`. Keep that order.
2. `categorical/cat_grouping_split_conjunction.py`, inner `_clone_node`: the same change (keep the
   line `clauses[v_copy] = list(clauses[v])`). Both call sites pass `w_uv`.

   ```python
   def _format_weight(weight: float) -> str:
       """Edge label for a (possibly fractional) trace count."""
       return f"{weight:.0f}" if abs(weight - round(weight)) < 1e-9 else f"{weight:.2f}"
   ```

   Use it for the `label=` of `dot.edge(...)` in `cat_grouping._build_dot`,
