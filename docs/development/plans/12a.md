# 12a — Exclude `credit_card_visual` from the default benchmark

**Problem:** report #12. `datasets/credit_card_visual/credit_card_visual.csv` has the same rows as
`datasets/credit_card_approval/loan_data.csv` (the files differ only by a final newline), and all
five views of the two datasets are identical. Every average across datasets counts this graph twice.
**Approach:** keep the file (it was added on purpose in commit `c68d7f9`, "a visual benchmark of the
grouping mechanism"), but leave it out of the default dataset list of both runners, the same way
`dummy_dataset` and `health_insurance` are. `--datasets credit_card_visual` still runs it explicitly.
**Depends on:** nothing.

## Changes

1. Confirm the duplication before changing anything. While writing this plan, `diff` showed that the
   two CSVs differ **only by the final newline** (`loan_data.csv` has none). The data rows are
   identical (the report's #12 section says so).

   ```bash
   diff datasets/credit_card_visual/credit_card_visual.csv datasets/credit_card_approval/loan_data.csv
   ```

   Expected: one hunk at line 1062 with `\ No newline at end of file`. If the output shows any other
   difference, stop and tell the user.
2. `categorical/run_all_categorical_experiments.py` and `categorical/run_all_metrics.py`: add
   `"credit_card_visual"` to `EXCLUDED_DATASET_DIRS`, with a comment: same rows as
   `credit_card_approval`; including both double-counts the graph in cross-dataset
   aggregates; pass `--datasets credit_card_visual` to run it anyway.
3. Update every help text and docstring that enumerates the excluded datasets (grep both files for
   `health_insurance` and `dummy_dataset`; e.g. the `--datasets` help "default: all, except
   dummy_dataset and health_insurance", the module docstrings, and `discover_dataset_csvs` /
   `discover_dataset_names`).
