# 3b — Flag unsatisfiable merged nodes (optional pruning)

**Problem:** report #3/#4/#10, follow-up. After 3a and 4a, a merged CONJUNCTION node whose clauses
contradict each other is kept as is (for example `Shift IN {Night} AND Shift NOT IN {Night}`). The
label is now correct, but a reader has to spot the contradiction, and the metrics count such a
node like any other.
**Approach:** mark every node whose label is unsatisfiable on its own with `"unsat": true` in the
structure JSON and draw it with a red border. Optionally (`--prune-unsat`, off by default) remove
unsatisfiable nodes and everything that can then no longer reach a class.
**Status:** optional. Run only if the user asks for it.
**Depends on:** 3a and 4a.

## Changes

1. `categorical/clause_algebra.py`: add

   ```python
   def clauses_unsatisfiable(clauses) -> bool:
       """True when no value of some base satisfies all of that base's clauses:
       two IN sets with an empty intersection, or an IN set fully covered by
       NOT IN sets. NOT IN clauses alone are always satisfiable here (domains
       are unknown, so an exhaustive NOT IN is not detected)."""
   ```

   Group clauses by base; for a base with `IN` clauses, compute
   `allowed = ∩ IN sets − ∪ NOT IN sets`; unsatisfiable if `allowed` is empty.
2. `categorical/cat_grouping_split_conjunction.py`, `_build_split_structure`: for every node with
   clauses (use the module's `clauses` state; `_split_then_merge` returns only `(labels, edges)`, so
   re-parse the final labels with `cat_duplicate_split_peer._split_label`-style parsing, i.e. split on
   `" AND "` and `_parse_in_label`), set `"unsat": True` on the node dict when
   `clauses_unsatisfiable(...)`. Do the same in `cat_duplicate_split_peer._deduplicate_labels` when it
   writes labels back (nodes it does not touch keep their flag from the input JSON).
3. Rendering: in the two `_build_dot_from_graph` functions (conjunction and dedup), pass
   `color="red", penwidth="3"` to `dot.node(...)` for flagged nodes. The functions receive only
   `labels` and `edges`; add an optional `unsat_ids: Set[str] = frozenset()` parameter, computed by
   the caller.
4. Optional pruning, behind a module-level flag `PRUNE_UNSAT = False` in the conjunction module and
   a `--prune-unsat` CLI option of `run_all_categorical_experiments.py` that sets it: after
   `_split_then_merge`, remove flagged nodes and their edges, then iteratively remove nodes that are
   neither class nodes nor have any outgoing edge left. Record
   `structure["grouping_status"]["pruned_unsat"] = <count>` (the `grouping_status` dict is created by
   8a; create it if absent).
5. `categorical/run_all_metrics.py`: new column `unsat_nodes` = number of nodes with
   `"unsat": true` (0 for BASIC and views without the flag). Add it to `METRIC_FUNCTIONS`,
   `SUMMARY_COLUMNS` and the markdown legend.

## Tests

1. `clauses_unsatisfiable([("X","IN",["a"]), ("X","IN",["b"])])` is True;
   `[("X","IN",["a"]), ("X","NOT IN",["a"])]` True; `[("X","IN",["a","b"]), ("X","NOT IN",["a"])]`
   False; `[("X","NOT IN",["a"])]` False.
2. Conjunction on `X_a > 0.5 -> Y_p > 0.5 -> X_b > 0.5 -> Class 1` yields one node flagged
   `unsat`; with `PRUNE_UNSAT = True` the result has no path to `Class 1` and no dangling nodes.
