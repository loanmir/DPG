# 8b — Optional clone budget / no-clone mode

**Problem:** report #8, first half. Even when the pass terminates, cloning shared nodes makes the
"grouped" view bigger than BASIC: adult_subset CONJUNCTION 24 → 35 nodes, 33 → 52 edges, 583 →
2,080 predicate characters, labels up to 124 characters. This goes against the purpose of grouping
(a more readable graph). After 8a, a terminating pass ends at most about 3× BASIC.
**Approach:** a configurable clone policy for the split and conjunction passes:

* `clone_policy="always"` (default, today's behaviour);
* `clone_policy="never"`: only merges that need no clone (case "u absorbs v" with `v` private, and
  case "v relabelled in place"); an edge that would need a clone is settled instead;
* `clone_policy="budget"` with `clone_budget` (float, e.g. 0.25): cloning is allowed while
  `clones < clone_budget × number of BASIC nodes`; after that, edges that would need a clone are
  settled.

**Status:** optional. It trades readability (fewer nodes) against grouping (fewer merges). Run it
only if the user wants a smaller view. The pipeline default stays `always`.
**Depends on:** 8a, 1b (same functions).

## Changes

1. `categorical/cat_grouping_split.py` and `categorical/cat_grouping_split_conjunction.py`: module
   constants `CLONE_POLICY = "always"` and `CLONE_BUDGET = 0.25`, read at the start of
   `_split_then_merge` (keep the signature). Before every `_clone_node(...)` call, check the policy;
   if cloning is not allowed, `settled.add((u, v))` and continue with the next iteration. Count clones
   with the existing `clone_counter`. Record the policy in `LAST_RUN_STATS`.
2. `run_all_categorical_experiments.py`: CLI options `--clone-policy {always,never,budget}` and
   `--clone-budget FLOAT`. Set the module constants after `importlib.import_module(...)` in
   `run_one_dataset`. Log both values to the W&B config.
3. Module docstrings: one paragraph on the policy and its trade-off.

## Tests

On a diamond `a→v`, `b→v`, `v→k` (all categorical except `k`): `always` → a clone exists;
`never` → no id contains `#` and the graph has no more nodes than the input; `budget` with
budget 0 → same as `never`.

## Validation

Run the pipeline three times into separate output roots under `outputs/plans_scratch/8b/`
(`--output-root`, `--no-wandb`), once per policy (budget 0.25). Run `check_views` and
`analyse_graphs` (`DPG_OUTPUTS_ROOT=...`) on each. Acceptance: `n_changed_paths == 0` for all three.
Report a table per dataset: CONJ nodes, edges, predicate characters, max label length, and the
number of BASIC nodes that were absorbed (merges achieved) under each policy. The user decides from
this table whether to change the default. Do not change it in this plan.
