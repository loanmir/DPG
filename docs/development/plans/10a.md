# 10a — Measure cycles, contradictory and redundant paths

**Problem:** report #10. DPG merges identical predicates across trees. Trees that test features in
different orders create cycles, and walking a cycle (or any cross-tree join) yields paths no row can
follow: titanic has 61% contradictory sampled paths, credit_card 5%, healthcare_stroke 26%. 47–77%
of paths on some graphs contain a test implied by an earlier one. This is inherent to how DPG builds
edges (report F1–F3). No per-tree path ever contradicts itself.
**Approach:** do not change DPG. Make the effect visible: compute per view the cycle size, the
share of contradictory paths and the share of paths with a redundant test, and log them with the
other metrics.

Why no structural fix: removing contradictory paths would need per-edge tree provenance and would
remove the cross-tree sharing that makes a DPG a graph rather than a forest. Row-by-row walkers
(`dpg_equivalence.predict_with_dpg`, the explainer) evaluate every predicate against the row, so
they never follow a contradictory path. The harm is to readers who take every path as a rule, and
to the transformations that used to merge contradictions into valid-looking rules (fixed by 3a/4a;
3b can flag them). Part of the redundancy on bank_marketing came from #14 (fixed by 14a).
**Depends on:** 0a. Run after 3a/4a/14a so the numbers describe the fixed pipeline (the
implementation itself does not depend on them).

## Changes

1. New module `categorical/graph_diagnostics.py`. It reuses the independent checker's constraint
   algebra instead of re-implementing it: add `categorical/graph_analysis` to `sys.path` and
   `import analyse_graphs as A`, as `latent_reachability.py` does. Public function:

   ```python
   def graph_diagnostics(structure: dict, dataset_name: str) -> Dict[str, object]:
       """Cycle and path-validity diagnostics of one view.

       Returns cycle_nodes (nodes in a strongly connected component of size > 1),
       largest_cycle, paths (number of source -> Class paths examined),
       paths_sampled (True when the graph was too cyclic to enumerate and
       A.N_SAMPLES random paths were drawn instead), contradictory_path_share,
       redundant_path_share and unreachable_nodes (labelled nodes on no
       source -> Class path).
       """
   ```

   Implementation outline:
   * labels/edges/nodes like `A.load_graph` does, but from the dict (factor the dict part of
     `A.load_graph` into `A.graph_from_structure(d)` and make `A.load_graph` call it; keep
     `A.load_graph`'s behaviour identical);
   * `onehot, domain, numeric = A.load_domain(dataset_name)`; cache per dataset name
     (`functools.lru_cache`), because every view of a dataset shares it;
   * `paths, sources, capped = A.enumerate_paths(labels, edges, nodes)`;
   * for each path `c, red = A.path_cons(path, labels, domain, onehot, numeric)`: contradictory if
     `not c.sat()`, redundant if `red` is non-empty;
   * unreachable = labelled nodes not on any examined path (when `capped`, report `None`, since a
     sample cannot prove unreachability);
   * SCCs with `networkx.strongly_connected_components`.
2. `categorical/run_all_metrics.py`: in the per-dataset metric computation (where
   `compute_metrics(structure)` is called for each variant), add the diagnostics for every variant,
   under keys `cycle_nodes`, `largest_cycle`, `contradictory_path_share`, `redundant_path_share`,
   `paths_sampled`, `unreachable_nodes`. Add them to `SUMMARY_COLUMNS` and the markdown legend. CLI
   flag `--no-diagnostics` to skip them (titanic's sampling takes a while). Handle exceptions per
   variant (log and store `None`) so one failure does not lose the other metrics.

## Tests — `tests/categorical/test_diagnostics.py`

`A.load_domain` reads `ROOT/datasets/<name>`, so do not create a dataset. Monkeypatch
`graph_diagnostics`'s cached domain loader to return a hand-made `(onehot, domain, numeric)`:
`onehot = {"X_a": ("X","a"), "X_b": ("X","b")}`, `domain = {"X": frozenset({"a","b"})}`,
`numeric = {"n"}`. Graph: `X_a > 0.5 -> n <= 3.0 -> X_a <= 0.5 -> Class 1` plus
`X_a > 0.5 -> Class 0`. Expect 2 paths, contradictory share 0.5, cycle_nodes 0. Add a cycle `n <= 3.0 ->
X_a > 0.5` and check `cycle_nodes`.
