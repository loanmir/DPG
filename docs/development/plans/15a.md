# 15a — Same cycle guard in the GROUPED-SPLIT pass

**Problem:** report #15. `cat_grouping_split._split_then_merge` has no cycle guard at all. When DPG
produces a cycle of same-feature `NOT IN` nodes (e.g. bank_marketing, `perc_var` 0.001:
`month NOT IN {apr} -> month NOT IN {aug} -> ... -> month NOT IN {apr}`), the pass clones around the
loop until its iteration cap, 7–104 s later, with a graph 29–52× larger than BASIC. In the stress
test SPLIT did not finish within 5 s on 209 of 911 graphs (181 of them at `perc_var` 0.001, the value
the pipeline uses for rain_australia and health_insurance).
**Approach:** exactly 8a's rule. Settle every edge whose target's original id lies on a cycle of the
input graph. The scratch test made while writing 8a ran the split pass with this guard on the
cases of 8a's evidence table: all finished in under 0.1 s with the BASIC node count (34 → 34,
52 → 52, 145 → 145, 424 → 424).
**Depends on:** 8a (helpers `_original_id`, `_cycle_node_ids` in `cat_grouping.py`).

## Changes

`categorical/cat_grouping_split.py`, `_split_then_merge`:

1. After `settled` is created: `cycle_nodes = _cycle_node_ids(nx_graph)` (import the helpers from
   `cat_grouping` together with the existing imports).
2. In the candidate loop, after `if (u, v) in settled: continue`:

   ```python
   if _original_id(v) in cycle_nodes:
       # Never merge into a node on a cycle: the clones would walk around
       # the loop forever (report #15; same rule as the conjunction pass).
       settled.add((u, v))
       continue
   ```

3. Add the same `LAST_RUN_STATS` reporting as 8a step 3 (module-level dict, filled at the end of
   `_split_then_merge`, written as `grouping_status` into the JSON by `_process_subdir`, and the
   runner warns on `capped`).
4. Module docstring: add a paragraph on the cycle rule (point to the conjunction script's docstring
   for the explanation). The warning text printed at the cap ("the input graph may contain a cycle")
   should now never fire. Keep it, since it is still the right diagnosis if it does.
