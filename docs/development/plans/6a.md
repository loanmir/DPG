# 6a — Dedup rewrites or drops a node only when it has exactly one parent

**Problem:** report #6. `cat_duplicate_split_peer._deduplicate_labels` tightens the label of `v`
using the condition of one parent `u`, without checking whether `v` has other parents. The new
label is then wrong for every path through the other parents:

```text
before:  u1 = X NOT IN {a} -> v,   u2 = W > 3.0 -> v,   v = X NOT IN {a, b} AND Y IN {p}
after:   v  = X NOT IN {b} AND Y IN {p}      (path via u2 no longer excludes X = a)
```

The drop branch has the same flaw: when `v`'s label becomes empty, only `u → v` is rewired, and the
edges from `v`'s other parents are silently lost on the next sweep. On real DPGs the stress test saw
harm only downstream of #3/#4, but the module is also a standalone CLI over arbitrary JSON, and the
docstring's equivalence guarantee assumes a single parent.
**Approach:** compute every node's parent set at the start of each sweep and skip any `v` with more
than one parent.
**Depends on:** 5a (same file). 11a later relies on this guard to protect trace-start nodes.

## Changes

`categorical/cat_duplicate_split_peer.py`, `_deduplicate_labels`:

1. At the top of each sweep (inside `for _ in range(max_iter):`, before
   `for (u, v) in list(weights.keys()):`), build the parent sets:

   ```python
   parents: Dict[str, Set[str]] = {}
   for (s, d) in weights:
       parents.setdefault(d, set()).add(s)
   ```

   (add `Set` to the `typing` import).
2. In the edge loop, right after the `if u not in labels or v not in labels:` block:

   ```python
   if len(parents.get(v, ())) != 1:
       # The rewrite restricts v by u's condition, which only holds on
       # paths through u. With other parents it would change the meaning
       # of their paths (and dropping v would lose their edges).
       continue
   ```
3. In the drop branch (`if not new_child:`), keep `parents` consistent for the rest of the sweep:
   for every rewired edge `(u, d)`: `parents.setdefault(d, set()).add(u)` and
   `parents[d].discard(v)`; after the loop `parents.pop(v, None)`.
4. Docstrings: in the module docstring's "Equivalence guarantee" section and in the "The pass"
   section, state the precondition: only children with a single incoming edge are restricted,
   because the restriction is valid only on the rows that arrive through that edge. Same in the
   `_deduplicate_labels` docstring.
