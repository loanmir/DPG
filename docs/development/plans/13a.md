# 13a — Drop absorbed nodes from `graph["nodes"]` in the GROUPED view

**Problem:** report #13. `cat_grouping._build_grouped_structure` removes absorbed nodes from the
top-level `nodes` list and from the edges, but copies `structure["graph"]["nodes"]` unchanged. Every
absorbed node survives as an isolated, unlabelled node (the empty grey box in the bank_marketing
GROUPED figure). `run_all_metrics.metric_node_count` counts `graph["nodes"]`, so the metrics table
reports 28 nodes for bank_marketing GROUPED instead of 27. The split and conjunction scripts rebuild
`graph["nodes"]` and are not affected.
**Approach:** filter the collapsed ids out of `graph["nodes"]` too.
**Depends on:** 0a.

## Changes

`categorical/cat_grouping.py`, `_build_grouped_structure`, in the `if "graph" in new_structure:`
branch:

```python
new_graph = dict(new_structure["graph"])
new_graph["nodes"] = [
    n for n in new_graph.get("nodes", [])
    if str(n.get("id", "")) not in collapsed_ids
]
new_graph["edges"] = new_edges
new_graph["links"] = new_edges
```

Update the function docstring: "Nodes whose ids appear in ``collapsed_ids`` are dropped" → mention
both the top-level list and `graph["nodes"]`.

## Tests — `tests/categorical/test_grouped_structure.py`

Chain `a: "X_p <= 0.5" → b: "X_q <= 0.5" → k: "Class 1"` through `_build_label_map`,

== {"a", "k"}` and that every id in `graph["nodes"]` has an incident edge.
